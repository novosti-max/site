# Пробный режим нового правила

Боевой бот файлы из этой папки **не использует**.

Кладёте сюда изменённый файл (например `textproc.py` с новым правилом). Сервер прогоняет через него журнал
настоящих постов MAX (последние 1500, `tools/replay.py`, ВК и сеть отключены) и выкладывает отчёт:
https://novosti-max.com/.well-known/acme-challenge/rb-shadow.txt — какие посты вышли бы иначе.
Отчёт обновляется раз в 30 минут и сразу после изменения файлов здесь.

Когда отчёт проверен и Никита согласен — файл переносится в корень ветки, а отсюда удаляется.
Пока здесь нет .py / .yaml, в отчёте написано «новое правило не проверяется».
