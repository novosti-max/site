# Новости в MAX — сайт-медиакит

Сайт для рекламодателей сети «Новости в MAX» (Никита + Илья): каталог каналов, подборка, заявка, страницы городов для поиска.

## Как устроено
- `data/channels.csv` — список каналов: тип, регион, название, подписчики, ссылки. Главный источник.
- `data/regions.json` — регион → страница города (`/reklama/<slug>/`) и подписи «в Воронеже».
- `data/site.json` — домен, контакт в MAX, коды Яндекс.Вебмастера / Метрики / Google.
- `update.py` — раз в сутки забирает с публичной страницы MaxFrame подписчиков, охват за 24 ч, аватарки и цену сети, пишет `data/stats.json` и пересобирает сайт.
- `build.py` — собирает статический сайт в `public/`.
- `deploy/install.sh` — установка на сервер (nginx, cron 06:10 МСК, HTTPS).

## Добавить канал
1. Добавить строку в `data/channels.csv` (ID берётся из ссылки MaxFrame).
2. Если регион новый — добавить его в `data/regions.json`.
3. Закоммитить. Сервер подтянет изменения в 06:10 или сразу: `cd /opt/novosti-max && git pull && python3 update.py`.

Каналы, которые есть в сетке MaxFrame, но не в CSV, пишутся в лог `/var/log/novosti-max.log`.
