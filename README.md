# Бот «Радар»: MAX → ВКонтакте

Служебная ветка. К сайту не относится, сайт живёт в ветке `main`.

Бот читает новые посты MAX-каналов сети (как админ без прав), убирает рекламу и посторонние новости
и публикует пост в группе ВК с карточкой из альбома «Карточки оповещений». Раз в день в 20:00 МСК выходит пост-перелив в MAX.

- `config.yaml` — группы, каналы-источники, номера карточек, правила. Ключей здесь нет.
- Ключи вводятся на странице настройки и хранятся только на сервере: `/etc/radar-bot/secrets.json`.
- Установка и обновление — автоматически, через `deploy/radar-bot-hook.sh` в ветке main (раз в минуту).
- Статус: `https://novosti-max.com/.well-known/acme-challenge/rb-status.txt`.
- Проверка логики: `python3 tests/test_bot.py`.
